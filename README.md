# 🤖 PsyBot — Telegram-бот психологической поддержки

## Структура проекта

```
psybot/
├── main.py                 ← точка входа, запускать отсюда
├── filters.py              ← кризисный фильтр
├── keyboards.py            ← inline-клавиатуры
├── requirements.txt        ← зависимости
├── .env                    ← токены (заполнить!)
├── .env.example            ← шаблон токенов
├── database/
│   ├── __init__.py
│   └── db.py               ← SQLite (aiosqlite)
├── services/
│   ├── __init__.py
│   ├── deepseek.py         ← DeepSeek API
│   └── throttling.py       ← защита от флуда
└── handlers/
    ├── __init__.py
    ├── start.py            ← /start + /help + кнопки меню
    ├── daily.py            ← /daily
    ├── chat.py             ← чат с ИИ + /reset
    └── media.py            ← стикеры/фото/голос
```

---

## Установка и запуск

### 1. Установите зависимости

В терминале PyCharm (Alt+F12):

```
pip install -r requirements.txt
```

### 2. Заполните .env

Скопируйте `.env.example` в `.env` и вставьте ваши токены:

```
BOT_TOKEN=ВАШ_ТОКЕН_БОТА
DEEPSEEK_API_KEY=ВАШ_КЛЮЧ_OPENROUTER
```

Получить ключ: https://openrouter.ai/keys

### 3. Запустите бота

Нажмите ▶️ на файле `main.py` или в терминале:

```
python main.py
```

|---------|----------|

---

## Как это работает

- **Кризисный фильтр** — перехватывает опасные сообщения *до* обращения к DeepSeek и отвечает контактами телефона доверия
- **Контекст диалога** — хранит последние 10 сообщений в SQLite
- **Длинные ответы** — автоматически разбиваются на части по 4096 символов
- **Таймаут** — 30 секунд, при ошибке пользователь получает вежливое сообщение
- **Совет дня** — берётся из БД или генерируется через DeepSeek и сохраняется
